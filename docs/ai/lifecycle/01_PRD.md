# 产品需求文档

> 轻刻健康 Android 客户端（qk-health-v2）：蓝牙体脂秤测量数据的记录、展示与同步。
> 覆盖型文档：每次迭代重写，不保留历史。

---

## 1. 项目背景

轻刻健康是一款配合蓝牙体脂秤使用的健康记录应用。用户在秤上完成称重后，App 读取体重与阻抗，
按体成分算法得出体脂率并长期保存，形成体重与体成分趋势。

本项目是旧库 qk-health-android 的**混合式重构**产物：旧库冻结为行为参考，可复用层
（协议解析、体成分算法、领域模型）按原语义移植，历史包袱层（SharedPreferences JSON 存储、
无分层的 Activity）重写为 DDD 分层工程。公司统一包坐标后，工程包名为 **com.xcwk.scalehub**。

## 2. 迭代目标

本次迭代为 **M1 收口与文档对齐**：在可运行骨架之上，把生命周期文档与黄金标准从脚手架模板
内容改写为真实工程描述，使文档反映实际模块边界、依赖方向与测试策略，为 M2 云同步开发提供
可靠上下文。同期完成公司命名空间迁移（com.qingke.health → com.xcwk.scalehub）。

## 3. 用户故事 / 需求清单

- 作为**测量用户**，我可以手动录入体重并看到最近测量列表，从而在未连秤时也能留档。

- 作为**接力的 AI**，我可以从生命周期文档读到真实架构，从而不必重新逆向工程代码。
- 作为**产品负责人**，我可以看到 M1~M5 路线图，从而了解剩余范围与优先级。
