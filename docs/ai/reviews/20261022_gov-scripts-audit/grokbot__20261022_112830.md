## 一、结论先行（含 10-22 更新）

1. **门禁不均匀，且「脚本」与「本机已安装 hook」已分叉。**
   - 模板 `scripts/governance/gov-pre-commit`（261 行，gov-owned）仍 **不 source `gov-config.sh`**，`SRC_PAT` 回退为 `src app lib packages` → 只认 `app/`。
   - **本机 `.git/hooks/pre-commit` = `gov-pre-commit-simplified`（71 行）**：master 禁直提交、可选会话归属、四模块 compileKotlin；**不跑** DEC/DevNotes、custom-checks、gov-validate。
   - `bs-install-hooks.sh` 仍复制模板长版 → 会覆盖精简版（双轨地雷）。
2. **强制 README 反思（R0 凑字数）已拆除（`b344d61`）**；蒸馏文件曾滞后，DEC-045 已统一 `.cursorrules`/`.clinerules`。
3. **`gov-custom-checks.sh` / `gov-code-check.py`：CI 不调用；精简 pre-commit 也不调用** → 相对 10-21「仅本地 app/ 时跑」**进一步塌陷**。
4. **PROTO-001/002 墙钟门禁**仍拦 pre-push/CI（`.cache/context.jsonl` 与 inbox 入库）。
5. **优点仍在**：负例测试、code-check 自证设计、CI 变更范围与 master 不取消、拥有区边界清楚、业务侧黄金向量/schema 测试。

## 四、真实缺陷（优先级）

### High

- **D1** 模板 pre-commit 不读 `gov-config.sh`（若装回则复发）。
- **D2** custom-checks / code-check 无 CI、无精简 hook。
- **D3** PROTO 墙钟 + 记忆入库 → CI/推送依赖时间。
- **D4** 无分支保护 + 特性分支裸 push 不跑 CI。

### Medium

- **D5** pre-push 校验工作区；**D6** R0 handoff 时效逻辑曾失效（反思拆除后部分代码路径废弃）；**D7** PROTO-003 文案与实现不符；**D8** worktree/hooksPath 兼容；**D9** 模板 scripts 校验软失败；**D10** emoji 自动 git add 整文件；**D11** lifecycle-audit 漏洞；**D12** next-note promote 可移植性。

### Low

死脚本引用、STATUS 非 CI 证据、分支 type 不一致、PyYAML 缺失体验、钩子复制件漂移等。

| P2 | STATUS 接 CI；DEC 分级；清理死脚本 | T / P |
