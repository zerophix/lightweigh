# DEC-050: Worktree 脚本与 hooks 工作树 ROOT

> 多 AI 并发隔离：一任务一 worktree；修复共享 hooks 在附属树上 ROOT 指错主树的问题。

---

## 决策

### A. `ses-worktree.sh`

项目自有脚本（`scripts/session/`）：

- `add <type>/<topic>`：从 `origin/master|main`（或本地 trunk）创建分支与 worktree  
  - 默认路径：`../<repo>-<topic>`  
  - `--in-repo`：`<repo>/.worktrees/<topic>`（gitignore）  
  - `--base <branch>`：可选基线  
- `list` / `remove <path|branch> [--force]`（禁止移除主工作树）  
- `doctor`：打印 `show-toplevel` / hooks 路径，提示是否需重装 hooks  
- 创建后打印 begin → claim → local-ci → push 下一步

### B. Hooks ROOT（worktree）

`gov-pre-commit-simplified` 与 `gov-pre-push`：**优先** `git rev-parse --show-toplevel`，
仅当失败或缺少治理脚本时才回退 `$0` 目录回推。

原因：worktree 共用主仓 `.git/hooks`，若用 `$0=.../.git/hooks/pre-commit` 回推，
会得到**主树**路径，导致 compile/validate/custom-checks 跑错树。

`bs-install-hooks` 安装后请在各树执行或依赖共享 hooks（已修逻辑）。
`commit-msg` 不依赖 ROOT，无需改。

### C. 文档

更新 `GC-multi-agent-collab.md` 与 `AGENTS.md` 一行指向 `ses-worktree.sh`。
