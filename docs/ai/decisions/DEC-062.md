# DEC-062: 治理检查改为 worktree 感知，使 DEC-050 的并发隔离真正可用

> 两条检查把 .git 当目录用，在任何 worktree 中恒失败，导致 agent 无法在 worktree 内提交、被迫回共享主树 —— 治理机制否定了协作机制。

---

## 决策

### 问题（实测证据）

worktree 下 `.git` 是 89 字节的**文件**（内容 `gitdir: <主仓>/.git/worktrees/<名>`），不是目录：

| 检查 | 原实现 | worktree 中的实际结果 |
|------|--------|----------------------|
| `check_status()` R0 | 拼 `ROOT/.git/hooks/<hook>` | 路径恒不存在 → `[FAIL] Git hooks 未安装` |
| `check_root_files()` R0e | 根目录文件逐一比对白名单 | `.git` 不在白名单 → `[FAIL] .git: 不在根目录允许清单中` |

而 `pre-commit` 会跑 `gov-validate`，于是 **worktree 里任何提交都被自身门禁拦死**。

**这不是假设**：DEC-050 建立 worktree 机制后，四个 agent 各自建了
`feat/ai-weekly-summary`、`feat/privacy-auth-flow`、`feat/settings-language`、
`feat/sync-network-status` 四个 worktree，**四个分支全部零提交**，
而主树上却出现带着**其他会话 session id** 的提交（`a403e12`、`97267b9`、`48dc474`）——
说明它们被迫退回共享主树提交，隔离机制形同虚设。

### 决策内容

1. **hooks 路径交给 git 解析**：新增 `_git_hooks_dir()`，调用
   `git rev-parse --git-path hooks`。主树返回 `<主仓>/.git/hooks`，worktree 返回同一主仓
   hooks（git 默认共享），两种形态都正确；git 不可用时退回原路径，**保守降级而非抛异常**。
2. **根目录白名单豁免 `.git` 文件**：`.git` 是 git 内部结构而非仓库内容，
   worktree 下它以文件形态出现。仅豁免 `.git` 这一项，**其余未知文件一律照旧拦截**。
3. **补 5 条测试**（含真实 `git worktree add` 的端到端用例），并做变异验证：
   撤掉豁免 → 根文件测试红；退回旧 hooks 拼接 → worktree 端到端测试红；还原 → 5 条全绿。
4. **不改 `ses-worktree.sh`** —— 它本来就是 worktree 感知的（用 `git rev-parse --show-toplevel`），
   出问题的是消费侧的校验模块。

### 明确不动的

- 不放宽白名单的其他项，未知根文件仍 fail
- 不改 CI 路径的判定（CI 环境原本就跳过 hooks 检查，见 DEC-008）
- 不改 `gov-owned.list` 归属

## Assumptions

| ID | 假设 | 依赖条件 | 失败影响 | 验证状态 |
|----|------|----------|----------|:--------:|
| A1 | `git rev-parse --git-path hooks` 在两种形态下均正确 | git ≥2.x | 解析错误则 hooks 检查失效 | 已验证（真实 worktree 端到端用例） |
| A2 | worktree 共享主仓 hooks 是 git 默认行为 | 未自定义 `core.hooksPath` | 钩子缺失被漏检 | 已验证（doctor 输出与实测一致） |
| A3 | 仅豁免 `.git` 不会放行其他脏文件 | 白名单其余项不变 | 根目录污染不再被发现 | 已验证（负向用例 `mystery.txt` 仍拦截） |
| A4 | git 不可用时降级不抛异常 | 退回路径恒返回 | 校验自身崩溃 | 已验证（损坏 gitdir 用例） |

## 方案评分

| 方案 | 评分 | 说明 |
|------|------|------|
| 交给 git 解析 + 定点豁免 `.git`（采纳） | 5/5 | 覆盖主树与 worktree，降级安全，白名单强度不降 |
| 把 `.git` 加进 ALLOWED_ROOT_FILES | 2/5 | 主树中 `.git` 是目录（`is_file()` 已跳过），加进白名单属无谓扩权，且掩盖了 worktree 语义 |
| 用 `CI=1` 环境变量绕过 | 1/5 | 伪造环境掩盖真实问题，其他规则同样失守 |
| 要求 agent 不用 worktree | 1/5 | 与 DEC-050 直接冲突，退回共享树碰撞 |
