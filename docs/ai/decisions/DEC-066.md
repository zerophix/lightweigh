# DEC-066: 流程即程序 —— 用可执行程序替代文字约束

> 2026-10-24 复盘：一个会话里人类需要反复说"去清理 worktree / 放后台 / 别问了去做"。
> 文字规则（AGENTS.md）已证明是弱约束：AI 每次都可能忽略；而人肉催办本身就是最大瓶颈。
> 本决策把流程收敛为**一个可执行程序 + 一个只调脚本的 Skill**。

---

## 问题（实测）

| 现象 | 后果 |
|------|------|
| 每个动作都要人类提示（清理 worktree、后台运行、合并顺序） | 人类成为流程的一部分，AI 无法自主推进 |
| 规则散落在 AGENTS.md / DEC / GC 文档 | AI 读不全、读了也可能不执行 |
| worktree 生命周期无归属 | 9 个目录堆积，人类发现并质问才处理 |
| 合并需要 12 步手工（同步/冲突/计数/CI/合并/清理） | 5 轮重复劳动 |

## 决策

### 1. 唯一入口：`wf-autopilot.sh`

| 子命令 | 作用 |
|--------|------|
| `status` | 一屏真相：任务批次、在途 PR、worktree 审计、**NEXT 命令**。任何 AI 进仓先跑它 |
| `advance` | 逐个 PR：同步 master（机械冲突自动解决）→ 派生物同步 → local-ci（走 wf-run 后台）→ 合入 → 删 worktree/分支。语义冲突停下列文件 |
| `start <T-XXX>` | 认领锁 + 建 worktree + 打印 target_files/验收 |
| `finish <T-XXX>` | `gov-task-done` 通过 → 提交 → 推送 → 开 PR |
| `clean` | 清理已合入 worktree/分支/孤儿目录 |

**约束**：`status` 是只读的；`advance` 只自动解决"派生/状态"文件冲突（registry、STATUS、03_TaskGraph、staged-claims），其余停给人。

### 2. Skill 只调脚本

新增 `.opencode/skills/dev-flow/`（SKILL.md + skill.yaml + binding.yaml）：内容是命令序列与"以脚本输出为准"，不重复叙述规则。Skill 被自动发现（已生效）。

### 3. AGENTS.md 首屏只留一条命令

任何 AI 读完第一屏即可行动；规则细节保留在 §10 映射表（规则→执行者→自查命令）。

### 4. 自动化优先于提醒

能自动的绝不提醒：清理、同步、合并、DoD 校验、注册表、计数。提醒类规则（如"记得后台运行"）只保留在约定栏，不假装是门禁。

## Assumptions

| ID | 假设 | 依赖条件 | 失败影响 | 验证状态 |
|----|------|----------|----------|:--------:|
| A1 | `advance` 的机械冲突清单覆盖了绝大多数并发冲突 | 单一写者规则生效（DEC-064） | 频繁停给人 | 已验证：9 个在途 PR 全自动合入（本轮实测） |
| A2 | `status` 输出足以让新 AI 自主开工 | 任务板有 ready AC + PR 元数据可读 | 仍需人解释 | 已验证：新会话按 NEXT 可直接执行 |
| A3 | 语义冲突必须人处理 | 不做自动改代码语义 | 冲突停止推进 | 设计如此（安全边界） |

## 方案评分

| 方案 | 评分 | 说明 |
|------|------|------|
| 程序入口 + Skill + 脚本化清理合并（采纳） | 5/5 | 把"人类催办"换成"程序执行"；文字只做索引 |
| 继续完善 AGENTS.md 文字 | 2/5 | 弱约束，实测一天内被多次忽略 |
| 全自动无人值守（含语义冲突自动修） | 1/5 | 语义冲突自动化风险高于收益 |

## 来源: 2026-10-24 人类要求"别靠文字约束，要真实的 skill 与脚本自动化；任意 AI 进来都知道怎么干"。
