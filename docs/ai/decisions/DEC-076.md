# DEC-076: 单一真源 —— AGENTS.md 生成各 AI 工具的规则文件

> 2026-10-24 复盘：Cursor AI 看 `.cursorrules`，OpenCode 看
> `.opencode/rules.md`，Cline 读 `.clinerules`。三个文件手动同步，
> 结果经常 diverge —— 有人按新 AGENTS.md 改码，另一个工具还是看旧规则。

---

## 决策

- **真源**：`AGENTS.md`（人类可读、版本控制）
- **派生**：`.opencode/rules.md`、`.clinerules`、`.cursorrules`
- **生成**: `bash scripts/governance/gov-sync-agent-rules.sh`
- **校验**: `gov-validate.py --check` → 比较真源与派生是否一致

## 生成逻辑

```bash
gov-sync-agent-rules.sh:
  1. 读取 AGENTS.md §1~§14（跳过"维护规则"章节）
  2. 提取关键规则行（开工命令 / 硬规则 / 文件操作原则）
  3. 写入 .opencode/rules.md / .clinerules / .cursorrules
  4. pre-commit: gov-sync-agent-rules.sh --check → 不一致退出 1
```

## 不动的

- True source 永远是 AGENTS.md，其他文件只能通过脚本修改
- 手改 `.opencode/rules.md` → `gov-validate` 判红
