# DEC-054: 主共享树多会话守卫（强制 worktree）

> 多 AI / 多会话共写同一 `.git` 时，HEAD 与配置会被互相覆盖；结构上用 worktree 隔离。

---

## 决策

1. **检测**：当前树为**主共享树**（`git-dir == git-common-dir`），且 `.cache/context.jsonl` 近 **2 小时**内有 **≥2** 个不同的 `session-start` → 判定并发。
2. **拦截**：`gov-pre-commit-simplified` 在上述条件下 **拒绝 commit**，提示改用 `ses-worktree.sh add …`。
3. **逃生**：确认本机唯一会话时，临时 `ALLOW_MAIN_TREE=1 git commit`。
4. **worktree**：隔离 HEAD / 工作区，只共享对象库（见 DEC-050）；默认路径 `../<repo>-<topic>`（repo 名现为 `lightweigh`）。

已在 PR #22（`11107a4`）落地代码与测试；本文件为漏档补写。

## Assumptions

| ID | 假设 | 依赖条件 | 失败影响 | 验证状态 |
|----|------|----------|----------|:--------:|

| A2 | 2h 窗口覆盖典型重叠会话 | 长会话可能误伤 | 可用 ALLOW_MAIN_TREE | 待验证 |

## 方案评分

| 方案 | 评分 | 说明 |
|------|------|------|
| pre-commit 守卫 + worktree（采纳） | 5/5 | 对症 HEAD/配置争用 |
| 仅文档约定 | 1/5 | 易被忽略 |
| 默认禁止一切主树提交 | 2/5 | 单会话过严 |
