# DEC-026: 逐页按原型重建 —— DEC-025 F/G 批落地

> 地基（令牌/组件/壳层）已由 DEC-025 换完；本批把六个二级页与首页按原型逐屏重排，
> 新增的页面级原语（页标题/返回钮/评分环/蓝牙环/月标头/风险行）全部收进组件库，
> 页面仍然只做组装。

---

## 决策

1. **图标收口（A）**：新建 `QkIcons.kt` 作为全 App 唯一图标选型点，引入
   `material-icons-extended`（Material Symbols 的 Compose 侧等价物——Compose 无官方
   Symbols 产物，同 24dp 网格同隐喻）。纪律：页面禁止 `import androidx.compose.material.icons.*`，
   一律经本表取图；换图标集只改一处。此前「趋势」用 DateRange、「设备」用 List 的
   语义错位随之修正（BarChart / MonitorWeight）。
2. **页面级原语（B）**：`QkPageTitle`（原型 .page-title）、`QkBackButton`（压栈页返回圆钮）、
   `QkScoreRing`（84dp 评分环，**按 score/100 画弧**而非原型的固定顶段——环要表达分的多少）、
   `QkDeviceHero`（150dp 蓝牙环：1px 外描边 + 12/25dp 两圈内嵌浅环 + 58dp 主绿圆心，
   版式取原型实测值，环不带动画）、`QkDateChip`（.history-date 月标头）、
   `QkRiskRow`（.risk 状态点行）。`QkListRow` 增 `icon` 参数（与文字 glyph 二选一）。
3. **首页（C）**：按原型六区块重排——体重卡（三指标格 + 四段条 + 隐藏开关 + 双按钮）→
   AI 询问 → 今日饮食（四格 + 三个记录胶囊）→ 目标/体重趋势 → 喝水/跳绳 → 习惯打卡/运动 →
   轻断食/生理期（浅底染色卡）→ 手动记录体重 → 最近测量 → 健康记录。原型没有的 8 个模块
   **不删**，编入同一套卡片语法（腰围并入体重卡第三格，轻断食/生理期用同尺寸浅底卡承接）。
4. **六个二级页（D~I）**：全部改为原型版式——分段控件替代旧 QkChip 筛选行；指标/数值/增减
   用 list-row 与三列行语法；设备页补上原型标志性的 .device-hero 蓝牙环；报告页评分改为
   评分环 + 状态标题；设置页按三个 section-head 分组。数据轴（趋势的 范围×时段、历史的
   时段筛选、月分组折叠、删除确认、DatePicker、账号三流程、法务弹窗）一律不动——
   本批只换视觉，不改行为。
5. **导航接线（F）**：我的页「更多」卡的 历史记录/设备管理 两个入口经 MineRoute 新回调
   接到壳层（Push History / SelectTab DEVICE），不新开局部导航布尔。
