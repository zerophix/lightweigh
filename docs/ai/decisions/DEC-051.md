# DEC-051: STATUS 门禁证据来自 local-ci / Actions

> 健康检查少「自报」、多「取证」。无分支保护时以本地 `gov-local-ci` 为权威。

---

## 决策

1. **`gov-local-ci.sh`** 每次结束（PASS/FAIL）写入机读文件  
   `.cache/local-ci-last.json`（gitignore；含 timestamp、git_sha、branch、各步 exit_code、result）。  
   成功后并调用 `gov-update-status.sh` 刷新 STATUS。
2. **`gov-generate-status.py`**「健康检查」：
   - **本地门禁**：读上述 JSON（主证据）
   - **GitHub Actions**：可选 `gh run list --branch`（辅证据；失败则「无数据」）
   - **文档校验**：若 local-ci 含 `gov-validate` 步，显示实测通过/失败
   - **禁止**对本 Android 仓执行 `npm run build`（删除旧 `--check-build` npm 路径）
3. R0f `.cache` 白名单增加 `local-ci-last.json`。

## Assumptions

| ID | 假设 | 依赖条件 | 失败影响 | 验证状态 |
|----|------|----------|----------|:--------:|
| A1 | 合入纪律仍会跑 local-ci | 无 Pro | STATUS 显示无证据 | 待验证 |
| A2 | generate-status / validate_status 模板区分叉 | upgrade 后重检 | 回归 npm 行 | 待验证 |

| 方案 | 评分 | 说明 |
