# DEC-053: src/main 缺同模块测试的 PR 提醒

> Danger 风格：改逻辑代码却无测试时留言警告；默认不红 CI。

---

## 决策

1. **`gov-test-guard.sh`**：相对 base 检测各模块 `src/main/(java|kotlin|jvm)` 变更；
   若同模块无 `src/test` / `androidTest`（含 testDebug）变更 → 触发。
2. **忽略**：`src/main/res`、`assets`、`AndroidManifest.xml`、图片字体等资源。
3. **CI**（`test-guard` job，仅 PR）：留言提醒；**默认 exit 0（warn）**。
4. **`--strict`**：失败，除非标签/正文 `allow-no-tests`（软放行）。
5. **`gov-local-ci`**：默认 warn 模式接入（不因缺测试而整门禁红）。

不依赖 GitHub Pro。

## Assumptions

| ID | 假设 | 依赖条件 | 失败影响 | 验证状态 |
|----|------|----------|----------|:--------:|
| A1 | 模块级测试即可，不要求同名测试类 | Android 四模块结构 | 偶发漏报/误报 | 待验证 |

## 方案评分

| 方案 | 评分 | 说明 |
|------|------|------|
| 默认 warn + 可选 --strict（采纳） | 5/5 | 少误伤资源/清单变更 |
| 默认 fail | 2/5 | 对小改动过严 |
