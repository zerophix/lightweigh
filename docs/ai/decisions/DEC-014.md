# DEC-014: 剩余黄金标准与站点元数据去模板化

> 把仍是模板内容的 reference/index.md、guides/index.md 与 mkdocs 站点身份改为
> 轻刻健康真实内容，收尾文档层。

---

## 背景

DEC-012 已重写生命周期 01~06 与黄金标准 architecture/index.md，但文档层仍有模板残留：

- `docs/reference/index.md`（黄金标准）通篇描述模板自身的工具链（MkDocs / gov-validate /
  脚本清单），未提及本工程的核心资产——体脂秤协议与体成分算法；
- `docs/guides/index.md` 概述自称「AI Project Collaboration Blueprint 的开发指南」；
- `mkdocs.yml` 的 `site_name` / `site_description` 仍是模板名，`site_author` 为未设置占位；
  而 `STATUS.md` 的名称字段正是从 `site_name` 读取，导致状态看板身份错误。

## 决策

- `docs/reference/index.md` 改写为项目技术参考：领域协议（okok-1 / okok-broadcast-1 /
  chipsea-cloud-1）、体成分算法（builtin-1 / okok-bia-1）、存储契约（Room measurements /
  ProfileStore）、模块与依赖、治理工具。
- `docs/guides/index.md` 概述改为本项目表述（保留治理框架的接入 / 迁移 / 决策流转指南条目）。
- `mkdocs.yml` 站点身份改为项目：`site_name` / `site_description` / `site_author`。
- 两份黄金标准经 `wf-promote.sh` 晋升，来源标注为本决策。

## Assumptions

| ID | 假设 | 依赖条件 | 失败影响 | 验证状态 |
|----|------|----------|----------|:--------:|
| A1 | 协议 / 算法清单与代码一致 | domain 包结构稳定 | 参考文档失真 | 已验证 |
| A2 | 改 site_name 不破坏 mkdocs 构建 | gov-sync-mkdocs 仅重写 nav | 站点构建失败 | 已验证 |
