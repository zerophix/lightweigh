# DEC-049: 特性分支 CI、Dependabot、本地密钥扫描

> 承接市场对比 P1：远程信号、依赖 PR、密钥扫描。用户不做 GitHub Pro。

---

## 决策

### A. 特性分支 push 触发 CI

`.github/workflows/ci.yml` 的 `on.push.branches` 增加与分支命名一致的通配：
`feat/**`、`fix/**`、`chore/**`、`docs/**`、`refactor/**`、`test/**`、`ci/**`，
并保留 `main`/`master` 与 `pull_request`。

保留 DEC-033：`concurrency` 对非 trunk 取消进行中的 run；纯文档变更跳过重型 Gradle。

### B. Dependabot

新增 `.github/dependabot.yml`：`gradle` 与 `github-actions`，`weekly`（周一），
`open-pull-requests-limit: 5`。私有仓可用，无需 Pro / 公开。

### C. 本地 gitleaks

1. 钉死版本 **v8.30.1**；`scripts/governance/gov-install-gitleaks.sh` 按 OS/Arch
   下载官方 tar.gz，用 `scripts/tools/gitleaks.sha256` 校验后装到
   `scripts/tools/gitleaks`（二进制 **gitignore**，不入库）。
2. `gov-secrets-scan.sh`：优先 PATH / `scripts/tools/gitleaks`；缺失则尝试安装；
   仍缺失则 **软警告**（退出 0）并打印 brew/脚本提示；二进制存在则
   `gitleaks detect` **硬失败**（发现即非 0）。
3. 接入 `gov-local-ci.sh` 与 `gov-pre-push`（模板拥有区分叉；upgrade 后重检）。
4. `.gitleaks.toml`：继承默认规则；allowlist 排除构建产物、设计导出、会话噪声
   （如已 gitignore 的 staged-claims / `ses-*` 会话 ID 历史误报）。
5. R0e 根目录白名单加入 `.gitleaks.toml`（`gov_validate_status` 模板区分叉）。
