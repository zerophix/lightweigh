# DEC-046: 本地门禁接入 gov-custom-checks 与 gov-local-ci

> 用户授权：立即把 gov-custom-checks 接到精简 pre-commit，并提供合并前本地 CI 脚本。不改远程/开源。

---

## 决策

1. **`gov-pre-commit-simplified`**：在已暂存 `.kt`/`.java`（四模块源码）时，于 compileKotlin 之后运行 `bash scripts/governance/gov-custom-checks.sh`；失败则拒绝提交。无源码暂存时跳过编译与 custom-checks（保持快速）。
2. **安装**：将更新后的 simplified **复制**到 `.git/hooks/pre-commit`；**不**调用会装回模板长版的 `bs-install-hooks.sh`。
3. **`gov-local-ci.sh`（项目自有）**：合并前一键跑 `./gradlew build`、`gov-validate.sh`、`gov-custom-checks.sh`；任一步非 0 即失败。
4. **文档**：AGENTS.md / `.cursorrules` 各补 1~3 行说明上述行为。

本决策不修改模板拥有区 `gov-pre-commit`（261 行）；钉死 install 脚本改指向 simplified 留待后续。

附带修复：`gov-custom-checks.sh` 在 `if` 体内调用 `gov-code-check.py` 时曾因 bash 忽略 `set -e` 而恒 `exit 0`，导致死 import 等违规不阻断提交；改为显式传递退出码。
