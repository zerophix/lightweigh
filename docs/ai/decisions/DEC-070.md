# DEC-070: 禁止绕过 —— 用钩子取代自觉

> 反复出现的根因不是"某个坑没修"，而是**我总能绕开自己的工具**：
> 手建 worktree（缺引导文件）、手工跨分支合并（共享状态冲突）、手改共享文件。
> 每一次绕过都会重新引入已经修过的故障。本决策把它们变成硬拒绝。

## 规则

| 绕过动作 | 检测 | 结果 |
|---|---|---|
| 手建 worktree（非 ses-worktree.sh） | 缺 `local.properties` 或 `gradle/dists` | pre-commit 拒绝，提示删除重建 |
| 手工跨分支合并（非队列） | 合并提交的父提交不是 origin/master 的祖先，且分支不是 `chore/integration-*` | pre-commit 拒绝，提示用 wf-queue |
| 手改派生数据 | 已有 DEC-064 守卫（仅 `chore/board-*` 允许） | pre-commit 拒绝 |
| 逃生口 | `ALLOW_UNREGISTERED_WORKTREE=1` / `--force` | 显式承担，留痕 |

## 原则

1. **能拦在钩子里的，不写进文档**：文档是索引，钩子才是强制。
2. **任何"我知道该怎么做"的路径，必须是最省事的那条**：队列一条命令、建树一条命令。
3. **事故 → 不变量 → 自动触发**：每次故障必须在同一会话内变成检查 + 测试 + 触发点，否则视为未修复。

## 来源: 2026-10-24 多次"同一类坑重复出现"的复盘
