# DEC-052: 黄金向量 / Room schema 变更守卫

> Danger 风格提醒：改契约资产必须显式 DEC 或放行，避免 AI 静默改绿。

---

## 决策

### 受保护路径

- `domain/src/test/resources/golden/`（黄金向量等）
- `infrastructure/schemas/`（Room schema 快照）

### 行为

1. **`scripts/governance/gov-schema-guard.sh`**：相对 base（默认 `origin/master` merge-base）检测变更。
2. **CI**（`ci.yml` job `schema-guard`，仅 `pull_request`）：
   - 有变更 → 在 PR 留言警告（DEC + Migration/测试要求）
   - **默认失败**，除非：
     - 标签 `allow-schema-change`，或
     - PR 正文含 `allow-schema-change` / `DEC-xxx`，或
     - 同范围 diff 含 `docs/ai/decisions/DEC-xxx.md`（本地/CI 共用）
3. **`gov-local-ci`** 增加同脚本一步（无 PR 时靠 diff 内 DEC 放行）。

不依赖 GitHub Pro / 分支保护；评论用 `pull-requests: write` + `GITHUB_TOKEN`。

## Assumptions

| ID | 假设 | 依赖条件 | 失败影响 | 验证状态 |
|----|------|----------|----------|:--------:|

| A2 | 私有仓 Actions 可写 PR 评论 | GITHUB_TOKEN | 仅 fail 无评论 | 待验证 |
