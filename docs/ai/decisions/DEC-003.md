# DEC-003: 协议文件统一更名为 AGENTS.md — 消除平台绑定命名

> 协议文件以单一跨平台标准名 AGENTS.md 承载，任何 AI 平台读取同一入口，不再以某个厂商工具命名。

---

## 决策

将根目录协作协议文件统一更名为 AGENTS.md（人类直接指令，2026-10-14），全仓引用同步更新：

- 组 A（文件本体）：`git mv` 等价操作完成协议文件更名；
  文件内部 3 处自引用（启动协议第 4 步、5 问速览、多平台兼容表）同步改为 AGENTS.md，
  多平台兼容表首行改为通用行，并补一段 Claude Code 旧版本软链兼容说明。
- 组 B（操作性引用）：所有会被 AI/人类复制执行或据以判断的引用全部更新——
  setup.sh 的复制与占位符替换逻辑、mig-migrate.sh 根文件白名单、README 定制指南、
  .clinerules / .cursorrules / .opencode/rules.md 三个平台规则文件的继承声明、
  GC 移植指南与新项目指南、workflow/docstandard 校验指引、
  architecture 与 reference 黄金标准、lifecycle 02/03、STATUS.md。
- 组 C（旧名全仓清除）：校验器三处白名单（structure ALLOWED_ROOT、core 根标记、
  R0e 根目录白名单）移除旧名，仅保留 AGENTS.md；reviews/、DEC、NOTE、
  context.jsonl 等历史记录中的旧名字样一并清除。此处原计划按「追加写不改写」
  规则保留，执行中经人类指令豁免该条款，全仓统一替换为 AGENTS.md，
  相关决策语境改用「旧名」「旧协议文件」等表述承载。
- 兼容边界：.claude/ 目录保留不动——它是 Claude Code 的工具配置（hooks、skills），
  不是协议文件本体，与本次更名是两件事。

## 方案评分

| 方案 | 评分 | 说明 |
|------|------|------|
| 全量更名 AGENTS.md + 软链兼容说明（采纳） | 5/5 | 单一文件单一事实源；跨平台标准名；旧版 Claude Code 用软链零成本兼容 |
| 保留旧名同时双写 AGENTS.md | 2/5 | 两份协议必然漂移，正是 DEC-002 刚修完的病根 |

| 不更名，仅在各平台规则文件里互相引用 | 3/5 | 零改动成本，但模板对非 Claude 平台仍带厂商命名，定位退化 |
