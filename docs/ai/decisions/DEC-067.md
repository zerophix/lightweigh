# DEC-067: 隐形失效防护 —— 让"没有报错但已失效"变得可见

> 一天里踩到的坑有一半不是"检查失败"，而是"检查根本没生效/验证的不是当前代码/状态没人回填"。
> 本决策把五类隐形失效变成机械可见。

## 五类隐形失效与对策

| 隐形失效 | 表现 | 对策 |
|---|---|---|
| 钩子副本过期 | 改了 `scripts/governance/gov-pre-*`，`.git/hooks` 还是旧版 → 门禁静默消失 | `gov-hook-doctor.sh` 逐文件 `cmp` + `--fix` 重装 |
| 各自绿、合起来红 | 每个分支 CI 绿，合并后 master 编译/测试红；无 CI 兜底 | `gov-post-merge-check.sh` 在 origin/master 的临时 worktree 全量复核 |
| 任务板漂移 | 已合入任务仍 pending → `wf-parallel` 重复派发（实测 4 次） | `gov-board-reconcile.sh` 以合并事实置 completed |
| 证据张冠李戴 | `.cache/local-ci-last.json` 是旧提交的证据 | `evidence_matches_head()`：`git_sha` 必须等于分支 HEAD |
| 共享状态事后剥离 | 分支先写坏共享文件，合并时再 strip（已冲突产生） | pre-commit **事前拒绝**功能分支提交派生数据 |

## 附带裁决：外部 PR 卫生

四条外部 PR 落后 master 86~107 提交且冲突；关闭不删分支、可逆。
规则：非本地在途分支 + 非依赖机器人 +（冲突 或 落后 >30 提交）→ 自动关闭并留模板说明。
执行：`gov-pr-hygiene.sh`（默认执行，`--dry` 预览）。

## 明确不动

- 合入权威仍是 local-ci 全绿（DEC-048）。
- 语义冲突一律停给人；脚本只处理派生/状态类冲突。
