# DEC-048: AI 开发 P0 — 任务 AC、短 AGENTS、PR 合入清单

> 承接市场对比报告三项最高 ROI：验收标准、精炼协议、无 Pro 下的合入仪式。

---

## 决策

### A. 任务验收标准（AC）

1. 新增 `docs/guides/GC-task-acceptance.md`，定义 `.ai/tasks.json` 中 `acceptance` 对象字段。
2. **编码前**任务必须具备可用 AC（`ready` 或字段齐全）；仅标题式 pending 不得开工。
3. `gov_validate_protocol`：`status == in_progress` 的任务若缺少非空 `acceptance.definition_of_done` → **FAIL**（GOV-PROTO-004）。
4. 对若干高价值 pending（如 T-045/T-046/T-049/T-058）写入真实或明确占位 AC；**不编造产品行为**。

### B. 短 AGENTS + 编码约定

1. 新增 `docs/guides/GC-coding-conventions.md`（模块地图、Gradle 矩阵、四件套、Room/黄金禁区、codebase-memory）。
2. 将 `AGENTS.md` 压缩为 ≤150 行：硬规则、启动、命令入口、指向 GC；长流程迁至既有 `docs/ai/guides/workflow.md` / 新 GC。
3. `.cursorrules` / `.clinerules` 轻量同步链接；**不恢复**强制反思。

### C. PR 合入清单（补偿无分支保护）

1. 新增 `.github/PULL_REQUEST_TEMPLATE.md`：强制勾选已跑 `gov-local-ci.sh`、粘贴摘要、AC、DEC、黄金/schema 未静默改动。
2. 更新 `GC-multi-agent-collab.md`：合入必须使用该清单。
3. R0f 白名单允许 `.github/PULL_REQUEST_TEMPLATE.md`；STRUCT 跳过本地 `design/`（gitignore 设计导出，避免中文文件名误杀）。
4. 模板拥有区 `scripts/governance/modules/*` 有本地分叉改动；`gov-upgrade --apply` 后须重检（同 DEC-047 Assumptions）。

## Assumptions

| ID | 假设 | 依赖条件 | 失败影响 | 验证状态 |
|----|------|----------|----------|:--------:|
| A1 | AGENTS 瘦身后 validate 仍通过（仅要求文件存在） | GOV-STRUCT 不解析 AGENTS 章节 | 需回填章节 | 待验证 |
| A2 | pending 不全填 AC 不导致校验 FAIL | 仅 in_progress 强制 | 无 | 待验证 |
| A3 | 用户继续不做 GitHub Pro | 人类约束 | PR 模板仅为纪律补偿 | 已确认 |

## 方案评分

| 方案 | 评分 | 说明 |
