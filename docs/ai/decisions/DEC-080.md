# DEC-080: 成本可见化 —— 人类等待时间必须可视

> 2026-10-24 复盘：`ship.sh` 在某些条件下卡 30 秒，
> `gov-local-ci.sh` 在冷缓存时跑 15 分钟。
> 开发者无法判断"应该等还是该走后台"。

---

## 决策

### ship.sh 等待预算 (≤ 5 秒)

```bash
ship.sh -m "..." <path>
# 内部: git add → pre-commit → git commit → git push → gh pr create
# 超过 5 秒 → 提示: "建议后台: bash scripts/workflow/wf-run.sh start ship -- ..."
```

### local-ci 成本显示

```bash
gov-local-ci.sh
# 输出: 车道 A: 42s  车道 B: 3m  总计: 3m42s  (冷缓存 +5m)
```

### 超过预算怎么办

| 环 | 预算 | 超时后果 |
|---|---|---|
| ship.sh | ≤ 5s | 提示走 `wf-run.sh` 后台 |
| dev-loop | ≤ 5s | 自动交给批次环 |
| local-ci | ≤ 10min | 提示分片优化 |
