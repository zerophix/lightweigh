# DEC-074: 任务画像 —— 门禁深度由改动路径决定，而不是一刀切

> 2026-10-24 复盘：一个 docs-only PR 被要求跑 full gradle + 全部 pytest，
>耗时 8 分钟但没有一条是相关的。反过来，一个 app/ 改动被放行了
> scripts/ 的恶意变更。
> 根因：画像（profile）是"这个改动属于哪类"，决定"该跑哪些门禁"。

---

## 五个画像

| 画像 | 允许改动 | 提交环 | 批次环 |
|---|---|---|---|
| docs | `docs/ design/ *.md` | 范围 + 语法 | 车道 A，不构建不测试 |
| test | `tests/ app/src/test/` | 范围 + 语法 | 全量 pytest |
| code | `app/ domain/ application/ infrastructure/` + 构建文件 | 增量编译 + 暂存区检查 | gradle + 受影响 pytest |
| gov | `scripts/ tests/ docs/ .github/` + 根规则文件 | 暂存区检查 + 语法 | 全量 pytest + 静态 |
| mixed | 任意（兜底，最严） | 并集 | 全量 |

**严格度**: `docs < test < code < gov < mixed`。降级只能通过 `GOV_PROFILE_FORCE=1 GOV_PROFILE=<p>` 显式进行。

## 推断规则

```python
infer_role(paths):
    kinds = set()
    for f in paths:
        if f.startswith("scripts/") or f.startswith(".github/"):
            kinds.add("gov")
        elif f.startswith("tests/") or "/src/test/" in f:
            kinds.add("test")
        elif f.startswith("docs/") or f.endswith(".md"):
            kinds.add("docs")
        else:
            kinds.add("dev")
    if kinds == {"gov"}: return "gov"
    if kinds == {"docs"}: return "docs"
    if kinds == {"test"}: return "test"
    return "dev"  # mixed → code+dev → mixed
```

## 角色默认画像（DEC-075 关联）

| 角色 | 默认画像 | 说明 |
|---|---|---|
| dev | mixed | 可能改任何地方 |
| test | test | 只改测试 |
| docs | docs | 只改文档 |
| gov | gov | 只改治理脚本 |
| review | 只读 | 不能写任何地方 |
