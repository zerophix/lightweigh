# DEC-001: AI 接力协作协议 — 以人类为枢纽的闭环交接

> 在 AI session 之间实现可验证、有强制力的接力，使跨 session 工作不丢失上下文、不被跳过。

---

## 决策

采用**以人类为枢纽的闭环接力模型**：AI session 结束时产出结构化交接（完成/未完成/决策理由/风险），新 AI 启动时强制读取接力信并向人类询问方向确认，人类确认后才能继续工作。

```ascii
Session A 结束
    │
    ├── session-end.sh: 4 项强制交接
    │   (完成 + 未完成 + 决策理由 + 风险 + next_why)
    │
    ▼
Session B 启动（session-begin.sh 自动提示）
    │
    ├── 显示未读消息数 + next_action + 确认状态
    ├── AI 必须问人类：上一个计划做 X，要继续吗？
    │
    ▼
人类确认或否决
    │
    ├── 确认 → task-board.sh confirm → 接着干
    └── 否决 → 人类指定新方向
    │
    ▼
Session B 工作 → session-end.sh → Session C
```

## 方案评分

| 方案 | 评分 | 说明 |
|------|------|------|
| 人类枢纽接力（采纳） | 5/5 | 人类是接力中枢，AI 不能自行决定下一个 session 做什么；强制读信 + 显式确认闭环 |
| AI 自主接力 | 2/5 | 不可行——新 AI 是全新实例，无记忆无义务，无法保证执行接力任务 |
| 纯数据驱动接力 | 3/5 | 数据持久是真（tasks.json 跨 session 存在），但 AI 不会自动读取，且无强制执行力 |
| 有状态后台服务 | 4/5 | 技术上可实现，但需外部守护进程，增加了部署复杂度，不适用于模板场景 |

## 决策理由

1. **AI 接力矛盾**：数据是接力的，但 AI 不是。磁盘上留下了接力信，但下个 AI 是全新实例，失去了之前的推理过程。人类才是 session 之间真正的接力员——人类决定何时启动 Claude、输入什么 prompt。
2. **强制读信**：新 AI 启动时**必须**执行 `inbox.sh list` + `inbox.sh read`，未读时直接干活 = 违规。此规则写入 AGENTS.md 接力铁律，并在 session-begin.sh 中自动输出提醒。
3. **人类确认**：AI 不能代替人类决定方向。`task-board.sh confirm` 保证了人类显式授权后才继续。跳过确认直接执行 = 违规。
4. **为什么要带 Why**：单纯的"下一步做 X"不足以让人类判断。附上理由（为什么做 X）后，人类可以更快决定"接着干"还是"走另一条路"。
5. **4 项交接清单**：完成 + 未完成 + 决策理由 + 风险，缺一不可。这是最小完备集——少了任何一个，下个 AI 都无法无上下文地开始工作。

## 替代方案分析

| 方案 | 未采纳原因 |
|------|-----------|
| Git 历史接力 | commit message 是单向通信，无法状态确认 |
| 外部数据库 + 后台进程 | 模板项目不应引入外部依赖 |
| Slack/飞书通知 | 收件箱不主动推送——AI 不能主动发消息 |
| 嵌入 AI prompt | 每次 session 都复制上下文到 prompt？不可维护 |

## 实现组件

| 组件 | 文件 | 职责 |
|------|------|------|
| 任务看板 + why | `scripts/workflow/wf-task-board.sh` | 每个任务和 next 附带理由，confirm 命令做显式确认 |
| AI 收件箱 | `scripts/workflow/wf-inbox.sh` | 接力信发送、读取、状态管理 |
| Session 收尾 | `scripts/session/ses-session-end.sh` | 4 项强制交接输出，更新任务板，发接力信 |
| Session 启动 | `scripts/session/ses-session-begin.sh` | 启动时提示未读消息 + next_action + 确认状态 |
| 接力铁律 | `AGENTS.md` | 4 条规则：必须读信、必问确认、必交接、必 4 项 |

## 已知局限

- **reasoning trace 缺失**：当前只传递决策结果，不传递推理过程（需要额外工具来结构化存 AI 思维链）
- **无自动通知**：收件箱文件在磁盘上，不会主动提醒人类
- **完成度验证不足**：无法自动校验新 AI 是否真的完成了交接任务
- **防静默跳过较弱**：session-begin.sh 提示 + AGENTS.md 规则约束，但人类可以直接覆盖
