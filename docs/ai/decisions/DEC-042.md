# DEC-042: 测量会话生命周期锚定 overlay

> 自定义导航壳不按 destination 提供 ViewModelStoreOwner，ScaleViewModel 实为 Activity 级——overlay 弹出不停会话，扫描/连接/倒计时脱离 UI 后台空转且残留状态污染重进。

---

## 决策

1. **屏幕离开即终结会话**：`ScaleRoute` 加 `DisposableEffect(Unit) { onDispose { vm.stop() } }`——overlay 弹出（返回、切页、关 App 前台切走等任何组合销毁路径）即停扫描、断连接、取消全部定时器。
2. **会话重建而非复活**：`SessionPhase.Closed` 是刻意的不可复活终态（reduce 钉死），不改状态机语义；改 `ScaleViewModel`：
   - `session` 改 `var`，构造参数持有，`newSession()` 工厂方法；
   - `start()` 检测 `session.closed` → 重建新会话并重挂 state 收集（旧 collect 先 cancel 再挂新的，防协程泄漏）；
   - VM 自持 `MutableStateFlow` 转发当前会话状态，会话切换时 UI 不闪断；
   - `stop()` 幂等（closed 不再重复 stop）；`ScaleIntent.Stop` 复用 `stop()`。
3. **`MeasureSession.closed` 提升为公开只读属性**（原 private）——VM 判定重建时机用，不暴露 phase 本体。

## Assumptions

| ID | 假设 | 依赖条件 | 失败影响 | 验证状态 |
|----|------|----------|----------|:--------:|
| A1 | overlay 弹出必经 composable 离开组合（DisposableEffect onDispose 触发） | 自定义 OverlayHost 移除即不再组合该 content | 极端热重载路径不触发 | 已验证 |
| A2 | 重建会话不影响已落库数据 | stop 只断链路，落库在 finishSave 已完成 | 无 | 已验证 |

## 方案评分

| 方案 | 评分 | 说明 |
|------|------|------|
| onDispose stop + VM 重建会话（采纳） | 5/5 | 状态机终态语义不破坏、重进可用、改动 3 文件 |
| 让 Closed 可复活（reduce 放开） | 1/5 | 破坏 DEC-024 状态机设计，非法转移合法化 |
| 按 destination 提供 ViewModelStoreOwner | 3/5 | 根治但动导航壳，影响全部 overlay 的 VM 语义，超出本问题范围 |
