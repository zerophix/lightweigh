# DEC-013: 测量聚合不变量加固

> **日期:** 2026-10-16
> **来源:** 对抗评审 R1-Q1（外部评审指出聚合仅做 null 归一）
> **状态:** 已生效

---

## 背景

对抗评审质疑：MeasureRecord 构造器只做 null 归一化，体重/体脂/阻抗无范围守卫，
"DDD 聚合"名不副实——非法值（如 fat=120、weight=999）可直接入库。

## 决策

MeasureRecord 构造期强制四条不变量：time>0；weight∈[1,400]；
impedance≥0；fat==-1 哨兵或∈[0,100]。违规抛 DomainException。
配套6 项不变量测试（每条守卫一个反例）。

## 取舍

- 不引入完整的 Weight/Impedance 值对象体系（那是 M4 档案/录入完善时的活），
  本决策只做"非法状态进不来"的最小闭环
- 与 data-schema 契约对齐：fat=-1 哨兵成为具名常量 FAT_NOT_CALCULATED
