# DEC-019: 统一文档术语与数量口径

> 同一件事在不同文档里被写成不同数字，读者无法判断谁对。本决策给全仓库的数量表述
> 建立唯一事实源与命名规范，并修复导致「同一编号两种解释」的编号冲突与索引生成缺陷。

---

## 背景

文档层积累了三类口径歧义：

1. **同一事实、两个数字**：README 写「21 项测试全绿」，指标文档写「单元测试方法 13」。
   两者其实都对——21 是 Gradle 变体展开后的**执行次数**，13 是源码中 `@Test` 的
   **方法数**——但文档从不标注用的是哪个口径，读者只能二选一。
2. **同一个词、多种含义**：「测试」既指单元测试方法，也指治理层 pytest 用例；
   「版本」既指文档修订号（vN），也指产品 `versionName`。
3. **同一个编号、两份正文**：并行会话手工新建决策时复用了已占用的 DEC-013 / DEC-014，
   合并后磁盘正文与变更日志、DevNotes 的记录互相矛盾，决策索引出现重复编号行；
   索引生成器又因 `gov-next-decision.sh` 写入的 YAML 前置元数据把标题解析成 `---`。

## 决策

- **术语表即事实源**：`docs/reference/index.md` §6「术语与口径」登记每个数量术语的定义与
  算法来源（模块数 / 源文件与行数 / 单元测试方法 / 测试执行数 / 治理测试用例 / 协议实现 /
  体成分算法 / 黄金向量 / 文档版本 / 产品版本），任何文档引用数量必须使用术语原名。
- **禁止裸口径表述**：`N 项测试`、`N 个用例` 这类不写口径的写法在现行文档中一律禁止；
  历史记录（decisions / changelog / inbox / reviews）不改写，其旧表述由术语表「历史记录
  口径对照」节统一解释。
- **数值只维护一处**：指标类数值以自动生成的 `06_Metrics.md` 为准，其他文档不重复维护成表；
  正文如需引用则改用术语原名并给出指向。
- **修正编号冲突**：把复用了已占编号的「测量聚合不变量加固」「对抗评审 R2」分别改号为
  DEC-017 / DEC-018，恢复 DEC-013（空模板校验）与 DEC-014（黄金标准去模板化），
  并修复索引生成器的标题 / 来源解析后重建唯一索引。

## Assumptions

| ID | 假设 | 依赖条件 | 失败影响 | 验证状态 |
|----|------|----------|----------|:--------:|
| A1 | 术语表口径足以覆盖现行文档的数量表述 | 术语定义与代码统计方式一致 | 新术语仍会歧义 | 已验证（漂移守卫测试扫描现行文档） |
| A2 | 并行会话不会再次复用 DEC-017 / DEC-018 | 取号统一走 `gov-next-decision.sh` | 编号冲突复发 | 待观察（本次改号后区间连续无重复） |
| A3 | 索引生成器修复不改变既有行格式 | awk 仅跳过前置元数据 | 索引 diff 噪音 | 已验证（仅标题/来源列变化） |

## 方案评分

| 方案 | 评分 | 说明 |
|------|------|------|
| 术语表 + 漂移守卫测试 + 编号修正（采纳） | 5/5 | 歧义消除可验证，历史记录不改写 |
| 只把 README 的 21 改成 13 | 2/5 | 表面一致，口径概念仍缺失，下次照样漂 |
| 统一改用「测试执行数」为唯一口径 | 3/5 | 数字随构建变体变化，不可静态复核 |

## 影响面

- `docs/reference/index.md`（黄金标准，经 `wf-promote.sh` 晋升）：新增 §6 术语与口径。
- `README.md` / `docs/ai/lifecycle/02_Architecture.md` / `docs/ai/lifecycle/05_Test.md` /
  `docs/architecture/index.md`：改用术语原名，并修正 ArchUnit「6 条规则」实为
  「4 条依赖规则 + 2 条自证元测试」的口径错误。
- `docs/ai/decisions/DEC-013…018.md` 与索引：修复编号冲突。
- `scripts/governance/gov-generate-index.sh`（上游拥有区）：标题解析跳过 YAML 前置元数据、
  来源解析去掉装饰星号——属**对上游基线的有意分叉**，应回推上游后收敛。
- `tests/unit/test_doc_terminology.py`、`tests/unit/test_decision_index_integrity.py`：漂移守卫。
