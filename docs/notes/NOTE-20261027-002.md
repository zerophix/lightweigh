# 反馈处理 SLA 与回复模板

> 版本：v1.0 | 负责人：客服团队 | 审批：DEC-086 | 关联：T-1012 Feedback Router

## 1. SLA 定义

| 优先级 | 反馈类型 | 响应时效 | 解决时效 | 回复模板 |
|---|---|---|---|---|
| P0 紧急 | 测量数据丢失 | 30 分钟 | 24 小时 | [模板1] |
| P1 重要 | 连接失败/固件异常 | 2 小时 | 7 天 | [模板2] |
| P2 普通 | 功能建议/使用问题 | 8 小时 | 15 天 | [模板3] |
| P3 其他 | 其他 | 24 小时 | 30 天 | [模板4] |

## 2. 分类规则

- **P0**: 涉及数据丢失、测量结果错误、账号丢失 → 紧急响应
- **P1**: 设备连接失败、固件更新失败、无法登录 → 快速响应
- **P2**: 功能使用疑问、优化建议、界面问题 → 标准响应
- **P3**: 其他非紧急问题 → 标准响应

## 3. 回复模板

### 模板1 - P0 数据丢失
```
你好，很抱歉给你带来数据丢失的体验。

我们已收到你的反馈（工单 #{{ticket_no}}），并且已经立即启动数据恢复流程。
- 预计恢复时间：24小时内
- 恢复方式：云端备份拉取
- 进度跟踪：本工单

如有疑问，请回复此工单，我们将第一时间处理。
```

### 模板2 - P1 设备连接
```
感谢你的反馈（工单 #{{ticket_no}}）。

针对你反映的「{{type}}」问题，我们已在排查中：
1. 请确认设备已进入配对模式
2. 请检查手机蓝牙是否开启
3. 必要时请尝试重新安装 App

我们的工程师将在 2 小时内跟进，7 天内给出解决方案。
```

### 模板3 - P2 功能建议
```
感谢你的建议（工单 #{{ticket_no}}）。

我们已收到你的反馈并加入产品评审列表，预计在下一个版本迭代中考虑支持。
如有进展，我们会在本工单回复。
```

### 模板4 - P3 一般问题
```
感谢你的反馈（工单 #{{ticket_no}}）。

我们已记录，你的问题或建议已提交给相关团队评估。
如有进展，我们会在本工单回复。
```

## 4. 处理流程

```
用户提交 → 客服分类 → 触发对应模板 → 工程师跟进 → 解决/关闭 → 用户确认
```

- 客服在 30 分钟内完成首次分类
- 未及时响应的工单自动升级到组长
- 超过 SLA 的工单自动发送 NPS 调查
