## 04. 测量全流程

### 主流程
1. 进入测量
2. 确认当前家庭成员与设备状态
3. 测量准备 (站姿、赤脚、设备平稳等说明)
4. 正在测量 (连接、重量稳定、采集身体成分数据)
5. 测量完成 · 身体成分报告 (已有)

### 需设计页面与分支
- [ ] 测量前的设备检查
- [ ] 测量准备说明
- [ ] 测量进行中 / 数据采集中
- [ ] 等待体重稳定
- [ ] 正在计算身体成分
- [ ] 测量成功结果页
- [ ] 测量失败与重新测量
- [ ] 蓝牙中断
- [ ] 用户提前离开秤面
- [ ] 数据采集不完整
- [ ] 设备返回无效数据
- [ ] 测量超时
- [ ] 重复测量 / 重复记录处理
- [ ] 测量取消确认
- [ ] 测量结果保存失败与重试

> 说明: 测量并非一个普通按钮操作，而是带有设备状态、数据采集状态和保存状态的业务流程。UI 必须明确区分 "蓝牙已连接" "测量已完成" 和 "结果已成功保存"。
