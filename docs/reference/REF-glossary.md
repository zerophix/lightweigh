# 术语表（Glossary）

> 来源：Notion「轻衡健康 / 00-规范 / DOC-术语表」
> 状态：草案 · 更新：Last Friday
> 真源声明：本文件是 Notion 页面的工程侧镜像，冲突时以 Notion 为准并回同步。

---

## 1. 文档短码

| 短码 | 含义 |
|------|------|
| DOC | 规范、说明、清单 |
| PRD | 产品需求 |
| DEC | 决策记录 |
| ROAD | 路线图 / 实施计划 |
| DES | 设计说明 |
| UX | 交互 / 流程 |
| UI | HTML 工作原型页 |
| REV | 评审意见 |
| MET | 指标 / 埋点 |
| QA | 测试用例与矩阵 |
| DEF | 缺陷记录 |

> 命名细则见 `DOC-目录与命名规范`。

---

## 2. 追溯 ID

| 符号 | 含义 |
|------|------|
| M# | 模块编号（如 M5 测量） |
| AC-* | 验收标准原文条目 |
| T-* | 任务或会签用例 ID |
| F-* | Figma 缺屏条目 |
| P0–P3 | 缺陷严重度 |

---

## 3. 工程名词

| 词 | 含义 |
|----|------|
| DoR | Definition of Ready：可开工条件 |
| DoD | Definition of Done：可标完成条件 |
| 准出 | 测试阶段出口条件全绿 |
| 会签 | 真机主路径由产品/工程签字确认 |
| 灰度 / 放量 | 分批把版本推给用户 |
| 钉扎 / pin | 并发开工前冻结的 PRD/schema/原型版本 |
| 治理门禁 | gov-validate / gov-local-ci 等合入前强制检查 |
| Token（设计） | 颜色、圆角、间距等主题变量（QkColor 等） |
| Token（账号） | 登录会话凭证；日志禁止明文 |

---

## 4. 产品与品牌

| 词 | 含义 |
|----|------|
| 轻衡 | 对外产品显示名 |
| lightweigh | 仓库名（可保留） |
| com.xcwk.scalehub | 技术包名（可保留，不对用户展示为产品名） |
| CloudBase | 默认后端同步方案 |
| SKU 白名单 | 支持的硬件型号清单 |
| 品牌口径见 | DEC-品牌与包名口径 |

---

## 5. 状态用词（文档）

仅用：**草案 / 评审中 / 已定稿**。

不用装饰符号，不写「最终版2」。
