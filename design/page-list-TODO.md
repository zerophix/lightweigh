## 16. 功能性缺口（2026-10-23 补充）

> 以下为页面/状态覆盖完成后，仍缺失的功能性场景。高优先级项建议在开发阶段前完成设计。

### P0：高频需求缺失

- [ ] **健康平台集成** — Apple Health / Google Health Connect 数据同步（2026 年健康 App 标配）
- [ ] **多设备切换** — 用户拥有家用秤 + 便携秤时的设备切换流程
- [ ] **医生/医疗报告导出** — 健康数据核心用例：生成可给医生看的结构化报告

### P1：体验完整性

- [ ] **设备校准引导** — 体脂秤定期校准流程
- [ ] **数据迁移（换机）** — 换手机时的显式数据迁移引导
- [ ] **身体重组洞察** — 肌肉↑ + 脂肪↓ = 身体重组（积极信号）的专门解读
- [ ] **周期对比分析** — 本周 vs 上周、本月 vs 上月的对比视图
- [ ] **目标进度曲线** — 目标达成随时间的变化曲线（不仅是进度条）

### P2：教育与激励

- [ ] **数据波动教育** — "理解你的数据"教育流程（体重日波动 1-2kg 正常）
- [ ] **智能提醒** — 自适应提醒（"3 天没测了"、"最近测量很规律"）
- [ ] **成就/激励系统** — 连续测量天数、减重里程碑
- [ ] **无障碍适配** — 字体缩放（老人模式）、屏幕阅读器、高对比度
- [ ] **儿童模式** — 家长追踪孩子成长的年龄适配视图 + 隐私边界
